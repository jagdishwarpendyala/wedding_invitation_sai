# Sai Jeevan & Sai Veena — Wedding Invitation V3

Six-screen static wedding invitation:
1. The Invitation
2. The Couple — individual portraits + family details
3. Together — combination photograph
4. The Auspicious Occasion
5. Counting Down to the Day
6. Final Blessing

The wedding animation/video is intentionally excluded.
The physical invitation-card display and separate family-blessing screen are also excluded.

Put these real files in `assets/images/`:
- groom.jpg
- bride.jpg
- engagement.jpg
- swami.jpg

Run locally with VS Code + Live Server on `index.html`.
